# Проверка формул ПНЛ

Отдельное локальное веб-приложение для аудита формул в чистовых Google Таблицах P&L. Исходные таблицы открываются со scope `spreadsheets.readonly`; приложение не содержит запросов записи.

Поле источника принимает прямую ссылку на любую Google Таблицу; встроенного списка файлов в интерфейсе нет.

## Запуск

```bash
cd pnl-formula-auditor
npm start
```

Откройте `http://localhost:4173`. Авторизация Google не требуется: приложение читает только таблицы, открытые по общей ссылке. Ограниченный ключ Google Sheets API хранится на локальном сервере в `server-config.json` и не передаётся в браузер.

## Развёртывание в Coolify

- команда запуска: `npm start`;
- переменные окружения: `GOOGLE_SHEETS_API_KEY`, `HOST=0.0.0.0`;
- порт приложения: `4173`;
- проверка состояния: `/health`.

## Правило аудита

- колонки «План» и «Факт» определяются по многоуровневому заголовку выбранного месяца и проверяются независимо;
- статьи извлекаются из первых 12 колонок по иерархическому номеру (`5.2`, `5.2.1` и т. п.);
- верхней считается статья, у которой существует хотя бы одна более вложенная статья с тем же префиксом;
- в плане и факте верхней статьи обязательны формулы;
- формула помечается подозрительной, если возвращает ошибку, пропускает непосредственную дочернюю строку или ссылается за пределы ветки;
- результат можно скачать как CSV, Google-таблица не изменяется.
